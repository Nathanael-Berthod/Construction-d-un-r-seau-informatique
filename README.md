# Construction-d-un-r-seau-informatique
Projet SAE2.01 (BUT R&amp;T) : conception et configuration d'un réseau d'entreprise multi-sites sous Packet Tracer. Mise en place du routage RIPv2, NAT, VLANs et SSH sur routeur WAN, avec sécurisation par ACL étendues (filtrage FTP, TFTP, HTTP/HTTPS et accès admin) sur plusieurs sous-réseaux 172.16.0.0/16.
